## 專案背景

客戶是一家專注於 B2B 市場的數位行銷顧問公司，舊網站已使用超過 5 年，視覺老舊且行動裝置體驗不佳，希望藉由改版提升品牌形象與詢問率。

## 技術堆疊

- **前端框架**：Astro（Static Site Generation）
- **樣式**：純 CSS + CSS Custom Properties
- **部署**：GitHub Pages + GitHub Actions
- **效能**：Lighthouse 分數 98+

## 設計亮點

### 視覺識別強化

採用品牌主色深藍搭配活潑的橘色作為 accent color，配合大標題對比創造強烈視覺印象。

### 清晰的服務說明架構

重新整理服務內容，以「問題 → 解決方案 → 成果」的敘事邏輯取代傳統的功能列表，讓潛在客戶更快理解服務價值。

## 成果

- 網站改版後詢問表單提交量增加 **140%**
- 跳出率從 78% 降至 52%
- Lighthouse 效能評分達到 98 分
- 行動裝置流量佔比從 30% 提升至 55%
